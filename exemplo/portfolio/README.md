# Portfólio final preenchido — percurso didático

Compile [portfolio-exemplo-undf.tex](../../portfolio-exemplo-undf.tex).
O exemplo reúne todos os projetos do percurso fictício declarado: P01,
validador de solicitações, e P02, guia de documentação de evidências.
Dois projetos não estabelecem quantidade mínima ou máxima para a modalidade.
Participantes, semestre e papéis são ilustrativos; não houve defesa real.

| Projeto | Registro de memória | Evidências |
| --- | --- | --- |
| P01 | [Relatório parcial](../projeto-aplicado/conteudo.tex) | [Programa](../projeto-aplicado/artefatos/validar_reserva.py), [casos](../projeto-aplicado/artefatos/casos.json) e saída reproduzível |
| P02 | [Registro parcial](registros/p02.md) | [Guia produzido](artefatos/guia-evidencias.md) |

O inventário, a síntese de cada projeto e a análise integradora mantêm esses
identificadores. O guia de P02 é um artefato documental, sem teste com leitores.
Os seis casos de P01 verificam somente as regras de um protótipo isolado.
Não há pesquisa com pessoas, implantação ou medição de impacto.

O relatório de agosto de 2026 foi usado apenas como referência de organização.
Nenhuma parte de artigo científico integra este portfólio.
Para escrever seu trabalho, use [o modelo preenchível](../../modelos/portfolio/README.md).
