\section{Exemplo de pseudocódigo}

\begin{undfpseudocodigo}{Cálculo da média de respostas válidas}{media-respostas}
Entrada: lista de respostas R
Saída: média das respostas válidas

Inicio
  soma <- 0
  n <- 0
  Para cada resposta r em R Faca
    Se r for valida Entao
      soma <- soma + r
      n <- n + 1
    Fim
  Fim
  Se n > 0 Entao
    Retorne soma / n
  Senao
    Retorne "sem respostas validas"
  Fim
Fim
\end{undfpseudocodigo}

O \algoritmoref{media-respostas} exemplifica pseudocódigo em bloco numerado, útil para descrever procedimentos de análise.
