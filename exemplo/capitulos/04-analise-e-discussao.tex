Este capítulo reúne exemplos práticos de elementos frequentemente presentes em um TCC. Os exemplos também funcionam como testes de compilação para os comandos de apoio do projeto.

\section{Exemplo de equação}

A equação de segundo grau pode ser representada por meio do comando amigável \verb|\equacao|:
\equacao[formula-bhaskara]{x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}}

A \equacaoref{formula-bhaskara} apresenta uma expressão numerada e referenciável. Também é possível usar uma fórmula destacada sem numeração:
\equacaosemnumero{E = mc^2}

\section{Exemplo de fluxograma}

\begin{undffluxograma}{Planejamento do TCC com início e fim}{fluxograma-planejamento}
\centering
\begin{tikzpicture}[
  node distance=1.1cm,
  terminal/.style={ellipse, draw, align=center, minimum width=3.4cm, minimum height=0.8cm},
  etapa/.style={rectangle, rounded corners, draw, align=center, minimum width=4.2cm, minimum height=0.8cm},
  decisao/.style={diamond, draw, align=center, aspect=2, inner sep=1pt},
  seta/.style={-{Latex[length=2mm]}, thick}
]
  \node[terminal] (inicio) {Início};
  \node[etapa, below=of inicio] (tema) {Definir tema};
  \node[etapa, below=of tema] (problema) {Formular problema};
  \node[decisao, below=of problema] (viavel) {Tema viável?};
  \node[etapa, below=of viavel] (metodo) {Escolher método};
  \node[etapa, below=of metodo] (texto) {Redigir TCC};
  \node[terminal, below=of texto] (fim) {Fim};

  \draw[seta] (inicio) -- (tema);
  \draw[seta] (tema) -- (problema);
  \draw[seta] (problema) -- (viavel);
  \draw[seta] (viavel) -- node[right]{sim} (metodo);
  \draw[seta] (metodo) -- (texto);
  \draw[seta] (texto) -- (fim);
  \draw[seta] (viavel.east) -- ++(1.6,0) |- node[pos=0.25,right]{não} (tema.east);
\end{tikzpicture}
\end{undffluxograma}

\section{Exemplo de pseudocódigo}

\begin{undfpseudocodigo}{MEDIA-RESPOSTAS(R)}{media-respostas}{Calcular média de respostas dado uma lista}
Entrada: lista de respostas R
Saída: média das respostas válidas

Inicio
  soma <- 0
  n <- 0
  Para cada resposta r em R Faca
    Se r for valida Entao
      soma <- soma + r
      n <- n + 1
    Fim-se
  Fim-para
  Se n > 0 Entao
    Retorne soma / n
  Senao
    Retorne "sem respostas validas"
  Fim-se
Fim
\end{undfpseudocodigo}

O \pseudocodigoref{media-respostas} exemplifica pseudocódigo em bloco numerado, com assinatura no padrão Cormen, título descritivo e fonte abaixo do quadro.

O ambiente \verb|undfpseudocodigo| é o comando único recomendado: ele evita quebra quando há pouco espaço restante na página e permite a quebra natural quando o bloco não couber.
